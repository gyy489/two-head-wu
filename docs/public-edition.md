# 公开版说明

这个仓库是两头乌基础平台从私人开发仓库导出的脱敏版本。它的目标是让读者能够检查结构、阅读实现、运行核心解析与包级测试，并在相同能力包约束下继续开发；它不用于复制仓库所有者的个人运行环境。

## 公开了什么

- `core/bin/wu` 及其确定性解析代码；
- Catalog、Agent、运行时、项目和能力注册表的脱敏声明；
- 九个系统基础设施能力和一个平台能力；
- 能力包的 manifest、接口、源码、契约、使用文档与测试；
- 最小能力包示例、开发指南和 CI 检查。

## 移除或替换了什么

- 账号、姓名、设备标识、本机绝对路径；
- 真实域名、服务器地址、SSH 目标、部署拓扑和访问映射；
- Token、Cookie、密码、私钥、操作者签名公钥和恢复材料；
- 私人记忆、对话、文档、日志、缓存、数据库和运行状态；
- 私人开发决策、内部验收报告，以及不属于“基础 9 + 平台 1”的能力包。
- 只验证未公开能力、私人 Skill Release 或生产拓扑的内部测试与启动器。

需要展示资源关系的地方使用 `example` 域名、示例身份和不可连接的脱敏资源。它们只用于说明数据结构，不是备用生产配置。

## 可运行层级

| 层级 | 需要什么 | 公开版支持 |
|---|---|---|
| 阅读架构和源码 | Git | 是 |
| 运行 `wu help` 与公开项目解析 | Ruby | 是 |
| 运行最小能力包示例 | Ruby / Shell | 是 |
| 运行单个基础能力包测试 | 对应包声明的系统依赖 | 视平台而定 |
| 使用消息渠道、定时任务和后台会话 | OpenClaw | 需要自行安装和接入 |
| 复现所有者的生产环境 | 私人绑定、凭据和数据 | 否，刻意不提供 |

完整两头乌会因为缺少 OpenClaw 而失去常驻入口、渠道、定时任务和后台会话，但能力包模型、Core 解析和独立 adapter 并不因此失效。OpenClaw 的接入职责见 [OpenClaw integration](openclaw-setup.md)。

## 二次开发约定

基于本仓库增加能力时，应保留能力包的独立生命周期：声明稳定接口、最小权限、显式依赖、兼容性、可执行测试和恢复方式。私有资源应由使用者在仓库外绑定，不要把示例资源改成真实凭据后提交到 Git。
