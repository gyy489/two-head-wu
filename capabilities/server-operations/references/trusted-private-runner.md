# Codex 驱动的受保护站点执行器

受保护执行器是一个确定性的本地服务，不是另一个 Agent。Codex 仍在当前对话中推理、构建页面和决定
何时报告结果；执行器只完成被严格限定的发布动作。

```text
你说“把这个网页部署到临时公开页面”
  → Codex 构建网页并调用公开适配器
  → 公开适配器在已登记项目工作区预检并冻结快照，生成 publication_id
  → 仓库内 IPC 客户端以 publication_id 找到快照，打包为常规 tar FD
  → 仓库外、独立服务账户的执行器只从 FD 解包到私有暂存，上传、重试、验证 HTTPS
  → 客户端返回脱敏结果 → Codex 写项目报告
```

## 为什么必须是受保护服务

与 Codex 同一账户、同一项目目录中的普通 CLI 不能构成秘密边界：任何能改写仓库的 Agent 也可能改写
它的代码、配置、请求或状态。因此，真实执行器必须以**独立系统服务账户**运行，且代码、配置、部署
身份、暂存、审计和单次发布状态都在项目仓库之外、普通 Agent 账户不可写的位置。

仓库内的 `private-runner/site-publisher` 是不受保护的固定客户端。它的公开 CLI 只接受发布 ID，不能用
参数、环境变量或配置文件改写目标、Socket、SSH、路径或凭据；内部会在已登记工作区读取对应冻结快照，
并把它打包为**常规 tar 文件描述符**交给固定 Socket。

`private-runner/site-publisher-service` 是供一次性安装使用的服务源码，不是当前已经运行的服务。真实
安装副本及其私有根目录必须在项目仓库外并由服务账户拥有。

取消逐次确认的代价是明确的：本地 Socket 获准组的进程可以提交获准项目/站点的静态发布物。服务限制的是
**目标和凭据边界**，不是自然语言意图证明、构建来源证明或通用的数据泄漏防护。安装者必须把 Socket 组
限制给可信本机工作流；普通 Agent 账户不得写服务私有根目录。

关键隔离是：受保护服务**绝不打开或遍历** Agent 可写的项目工作区，也不需要取得其 `var/server-ops/`
读取或遍历 ACL。它只接收客户端给出的常规 tar FD，在私有根目录中安全解包，再验证归档、请求摘要和
发布标记。项目工作区只由不受保护客户端读取，因而其中的路径竞争不会升级为服务账户读取私有资料。

## 固定行为

已安装的执行器必须：

1. 公开 CLI 只接受 `publication_id`；服务端把请求和归档 FD 都当作不可信输入。
2. 只支持 `private-site` 和 `public-site`；配置把已登记项目、可用站点和两个固定站点映射固定下来，
   不能接受主机、端口、远端路径、命令或新站点。
3. 校验请求格式、有效期、一次性状态、项目/站点绑定、归档类型与大小、归档路径、冻结快照摘要和发布
   标记；失败时不传输。
4. 只将归档 FD 解包到执行器自身拥有的发布暂存区；不要改成由服务读取项目工作区路径。随后使用专用、
   低权限部署身份上传。
5. 在当前发布连接中自动重试，最多 4 次、每次上传总时限 5 分钟、每次失败间隔 5 秒；客户端最多等待
   30 分钟。两个站点都只有在各自固定 HTTPS 地址读回
   同一发布 ID、站点 ID 与内容摘要的标记后才报告成功。它不是跨夜持久队列。
6. 只保存脱敏审计；不把主机、远端目录、完整命令、凭据或私有配置回传给客户端。

完整静态暂存只在当前同步发布期间存在，完成或失败后立即删除；脱敏状态/审计默认保留 90 天且有总数上限，
不能作为 Socket 组成员的长期文件仓库。

远端部署身份应只能写两个静态站点根目录，不能取得交互 shell，不能改系统配置，也不能访问数据库。
执行器不能、也不会改 FRP、Nginx、HTTPS、DNS、数据库、杭州服务器或法国机器。

## 一次性安装边界

真实上线需要由操作者一次性安装受保护服务，而不是让 Codex 从旧笔记中猜测连接。安装时：

- 将执行器代码和其私有配置放在项目仓库外；服务账户独占读写权限。
- 为服务账户配置仅用于两个站点的专用、低权限部署身份和最小 SSH 配置。
- 将 IPC Socket 组限制给需要提交发布物的可信本地调用方；不提供任意命令接口。
- 对两个站点做首次真实上传和 HTTPS 发布标记验收。

Mac 的目录所有权、Socket 组、LaunchDaemon 与首次验收的具体约束见
[生产安装契约](production-installation.md)。它使用服务账户可写、组仅可连接的持久运行目录，而不是让服务
账户在 `/var/run` 中创建 Socket 或以 root 常驻运行。

这不是以后每次发布的确认步骤。一次性安装和验收完成后，用户对 Codex 的直接发布请求即可自动完成
受限两站发布。

## 当前仓库状态

本仓库只保存 IPC 协议、客户端、执行器**安装源码/参考实现**和无真实服务器的模拟测试；没有已安装的
服务、真实两站映射或部署身份。服务未就绪时客户端必须失败关闭，不能降级为同账户脚本或直接 SSH。
